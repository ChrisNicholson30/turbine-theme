Instruments

Eighteen tokens drive the whole file

Each gauge shows the token in the current regime and its contrast against the canvas. Click a swatch to copy the hex.

AA is 4.5:1, AAA is 7:1. Dividers and disabled text sit below the floor on purpose: dividers are decoration, and disabled text is exempt under WCAG 1.4.3. Focus rings use the accent, which clears 3:1 for non-text UI in every regime.

Pre-flight

Install in three steps

One command installs the theme into Zed's user themes folder and registers a daily updater, so the file on disk always matches the latest release. No restart needed: Zed watches that folder.

1

Run the installer

macOS and Linux. It downloads turbine.json into ~/.config/zed/themes, keeps a local copy of itself, and schedules a daily update with launchd, a systemd user timer, or cron, whichever your system has.

curl -fsSL https://raw.githubusercontent.com/chrisnicholson30/turbine-theme/main/install.sh | bash

Prefer no background job? Append -s -- --no-auto and update by hand with ~/.local/share/turbine-theme/turbine.sh update. Remove everything with … uninstall.

2

Pick a regime

Run theme selector and choose Turbine Hypersonic, Turbine Supersonic or Turbine Subsonic. To follow the OS instead, set light and dark variants in settings.json:

// settings.json
"theme": {
  "mode": "system",
  "light": "Turbine Subsonic",
  "dark": "Turbine Supersonic"
}
3

Check on it any time

The updater only replaces the file when the theme actually changed, and logs what it did.

~/.local/share/turbine-theme/turbine.sh status
✓ theme installed: ~/.config/zed/themes/turbine.json (3f1c9e2a7b04)
✓ schedule: launchd, every 24h

Working on the theme itself?

Clone the repository and load it as a dev extension instead. Zed reads the folder on disk, so edits and git pull show up straight away.

  1. git clone https://github.com/chrisnicholson30/turbine-theme.git
  2. Run zed: install dev extension and pick the folder.
  3. Rebuild and validate with python3 build/build_theme.py and python3 build/validate_turbine.py themes/turbine.json build/schema_keys.txt.
Hypersonic

Laptops on battery, OLED displays, low light. A black pixel is an unlit pixel, so the canvas, gutter and terminal are all #000000.

Supersonic

The desk default. Real but modest OLED savings, tuned for multi-hour comfort on any panel.

Subsonic

Daylight, glare, outdoor work. Not a battery saver: on OLED it is the most expensive of the three.
